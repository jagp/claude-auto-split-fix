# CLAUDE.md

## What this is

A single-file, unofficial VS Code extension. Claude Code's toolbar button opens a new conversation in a _new, locked_ editor group; this extension detects that one specific change and moves the tab back into the previously active group.

## Commands

### Build

```sh
npm install            # installs vsce + @types/vscode; no runtime deps
npm run package        # -> dist/claude-auto-split-fix-<version>.vsix
```

### Lint

```sh
trunk check
trunk fmt
```

## Package comments

- the package should be exactly the manifest, `extension.js`, `icon.png`, README, CHANGELOG, and LICENSE.
- `extension.vsixmanifest` is **generated by vsce** at package time from
  `package.json`. Never hand-edit or commit
- `publisher` is `jbot-local`, a placeholder for local VSIX installs. It must become a real publisher ID before any marketplace publish.
- `--no-dependencies` required setting; without that flag vsce would try to bundle node_modules

### Linting

- Linting is Trunk (`.trunk/trunk.yaml`: prettier, markdownlint, yamllint,
  shellcheck, plus security scanners).
- `.trunk/` is excluded, not tracked

## Repo conventions

- Settings namespace is `claudeAutoSplitFix.*`. It lives in two places that
  must stay in sync: `CONFIG_SECTION` at `extension.js:4` and
  `contributes.configuration.properties` in `package.json`.
- New command IDs should use the same prefix (`claudeAutoSplitFix.*`), with
  palette category and output channel named "Claude Auto-Split Fix".

- `icon.png` is 128×128px; downscale if a file with matched name but larger dimensions is found in root
- Ignore /assets going forward
- `dist/` holds the current build and past releases. Not tracked
